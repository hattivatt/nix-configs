# Global instructions

- Keep changes focused on the task. Follow existing project conventions.
- Never add code comments or docstrings. Write self-explanatory code instead.
- If a required tool is unavailable, run it temporarily with Nix, preferably
  using the project's pinned environment when available. Do not install it
  globally.
- Run relevant checks. Report failures and checks you could not run.
- Preserve unrelated changes. Ask before destructive actions.
